### 漫画源持久化

已实现仓库领域模块、专用状态/脚本表、源码哈希与版本缓存、设置/数据/Cookie 持久化、配置导入导出与启停/设置管理接口、备份表清单接入。重新同步保留停用标记，导出的配置不含会话凭据。旧接口继续兼容，数据库仅新增表，不删除或迁移现有业务数据。

验证命令：`npm run test:manga-storage --prefix backend`（4 项），`npm run test:manga-engine --prefix backend`（17 项）。源状态恢复测试使用重建 store/map 和运行时模块模拟重启，不把它描述为操作系统进程重启演练。

限制：当前存储适配器仍为 SQLite；公开源运行时仍是站点共享实例，不表示已实现每访客登录隔离。Cookie/源状态保存在私有表中而非公开 settings。移除仓库不删除历史状态，便于恢复；重新导入同 ID 会复用其状态。脚本缓存每次显式同步仓库失效；首个成功初始化后再写缓存，不缓存执行失败的脚本。

新增接口位于现有漫画源管理 API 下，没有新增顶级后台入口或改变页面布局：

- `GET /api/admin/venera-sources/export`：不包含私有状态的配置下载。
- 原 `POST /api/admin/venera-sources/import` 兼容 `{url}`，新增 `{file,mode:'merge'|'replace'}`。
- `PATCH /api/admin/venera-sources/:sourceId`：启停。
- `GET/PUT /api/admin/venera-sources/:sourceId/settings`：声明过的源设置。

接口接入现有管理 UI 尚待后台模块迁移一起验收，不能仅凭接口实现就声称按钮已全部接好。
