如何添加我的节点

    
工作方式：VPS 用 vnStat 记录网卡流量 → 博客每 5 分钟通过 SSH 加密读取 → 在这里查看账期、图表和提醒。不需要购买域名或配置 HTTPS 上报。

    
    
      
  1. 准备自己的 VPS
    需要能通过 SSH 登录、有 sudo / root 权限的 Debian / Ubuntu 服务器。机场订阅或只有代理连接参数的节点，无法安装采集器。
    2. 
      
  2. 添加服务器资料
    点击页面顶部“添加节点”。名称自定义，填写 VPS 的 IP、SSH 端口，网卡保留 auto。NAT VPS 填共享 IP 与分配给你的 SSH 外部端口。
    3. 
      
  3. 填写套餐
    按服务商订单填写额度、重置日和计费方式。不确定时选择“套餐暂未确认”，以后可以补全。
    4. 
      
  4. 配置 SSH 查询
    采集方式保留“SSH 加密拉取”。保存后在 VPS 执行弹窗中的接入命令，再将最后输出的 SHA256 主机指纹填回页面。
    5. 
      
  5. 测试并查看结果
    点击“保存指纹并测试拉取”。连通后每 5 分钟自动读取；新安装 vnStat 需要等约 5–10 分钟才有首批流量。
    6. 
    

    
SSH 拉取与博客网页使用 HTTP / HTTPS 无关，私钥保留在博客服务器本地。网页本身使用 HTTP 的登录风险仍然存在。原有 HTTPS 上报节点继续兼容，也可在“节点设置”修改采集方式后改用 SSH。

    
这里统计 VPS 网卡流量，包含代理、SSH 和系统更新等用量。安装之前没有记录的流量无法自动恢复。
